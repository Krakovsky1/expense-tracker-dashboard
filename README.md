# Expense Tracker Dashboard

Modern expense tracking web application built with PHP, MySQL and Chart.js.

## Features

- User authentication
- Transaction management
- Budget management
- Category management
- Monthly filtering
- Financial analytics
- Interactive charts
- Responsive dashboard UI

## Tech Stack

- PHP
- MySQL
- Chart.js
- HTML/CSS
- JavaScript
